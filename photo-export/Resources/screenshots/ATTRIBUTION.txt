Bundled stock photos for screenshot mode
==========================================

These 27 JPEGs are the curated content the app shows when launched with
`--screenshot-mode` for marketing-screenshot capture. The plan and design
notes live in `docs/project/plans/screenshot-automation-plan.md`.

-----------------

Why these ship in release builds
--------------------------------

The plan (Phase 2 trade-offs) deliberately chose to compile the photos
into every build rather than `#if DEBUG`-gate them, so that:

- Anyone who clones the repo and runs `scripts/screenshots/capture.sh`
  gets byte-equivalent output regardless of build configuration.
- The screenshot-mode binary stays bit-for-bit identical to the App
  Store binary modulo unlock via the `--screenshot-mode` launch arg,
  which means the reproducibility property survives across release
  cuts.

The trade-off is ~10 MB of binary bloat shipped to App Store users who
never see these photos. Acceptable given the binary size.

If file size becomes a concern, the gate is one `#if DEBUG` around the
`bundledImageExtensions` lookup in `ScreenshotPhotoLibraryService.swift`.
